# SvenInt v3
A mod for Sven Co-op that improves gameplay.

Supported versions of the game: 5.26, 5.25 and 5.11

#### Console Variables/Commands
Type in the console the following command: `sc_printcvars all`.

The command above will print information about each ConVar/ConCommand that belongs to the mod.
