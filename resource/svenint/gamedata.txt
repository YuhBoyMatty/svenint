"GameData"
{
    // Brief information on GameData:
    //
    // Now, any data we're looking for (SvenInt's core & user created Features) is containted here
    // Just for case, if we're missing this file or we cannot find any data we look for, SvenInt (not features) will fallback
	// for use of statically built patterns & defined offsets, though it will work for Windows only.
    //
    // There's option to look up data via RVA only (Relative Virtual Address) depending on the game version, which is highly efficient since we
    // don't need to scan any patterns, just get the RVA offset and apply it to the pointer of the DLL's base allocation
    // By default, we prefer RVA over pattern scanning just to speed up the load time, of course one of the cons is that if
    // the game gets an update, I (or maybe you as a dev) have to recalc all RVA offsets again D:
    //
    // Section "RVA" is used both by Windows & Linux (in case of Linux if the version of the game is 5.26 or earlier, since Sniper has no brain so he removed debugging symbols :P)
    // Section "Offsets" is used by Windows & Linux, based on the game version it gets an offset to a virtual method, class member, etc...
    // Section "Patterns" is mostly used by Windows, although nothing prevent you to use it on Linux too
    // Section "Symbols" is used only by Linux, since we have debugging symbols in Linux binaries, super easy to look up for any data!
    // Well, it was that easy.. Since the version 5.26 now we don't look up for debugging symbols but use RVA offsets.
    // But, symbols look up will be used in any version older than 5.26 (5.25, 5.22, etc)
    //
    // Pattern "__MsgFunc_ServerVer" in section "Patterns" is used both by Windows & Linux to look up for the game version, so if it fails, SvenInt will stop loading
    // This section pattern is mostly used in sections "RVA" & "Offsets", but the most important is that SvenInt uses the obtained game version to conclude which
    // interfaces of various structs to use, so it can provide compability with various Sven versions (i.e. class WeaponsResource has different size in 5.11, 5.22, 5.23)
